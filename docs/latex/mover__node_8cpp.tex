\doxysubsection{Detailed Description}
ROS 2 Node for controlling a robot\textquotesingle{}s movement by publishing velocity commands and subscribing to odometry data. 

This node allows the user to input linear and angular velocities via the terminal, publishes these commands to the {\ttfamily /cmd\+\_\+vel} topic, and logs odometry data from the {\ttfamily /odom} topic.
