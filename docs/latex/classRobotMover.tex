\doxysubsection{Detailed Description}
A ROS 2 Node for controlling a robot\textquotesingle{}s movement. 

The \mbox{\hyperlink{classRobotMover}{Robot\+Mover}} class provides functionality to\+:
\begin{DoxyItemize}
\item Publish velocity commands to the {\ttfamily /cmd\+\_\+vel} topic.
\item Subscribe to the {\ttfamily /odom} topic to log odometry data.
\item Handle user input for controlling the robot\textquotesingle{}s movement. 
\end{DoxyItemize}
