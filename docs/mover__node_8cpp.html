Detailed Description

ROS 2 Node for controlling a robot's movement by publishing velocity commands and subscribing to odometry data.

This node allows the user to input linear and angular velocities via the terminal, publishes these commands to the /cmd_vel topic, and logs odometry data from the /odom topic.
